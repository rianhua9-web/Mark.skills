# 🧠 mark 渐进思想顾问使用指南

## 📖 前言

欢迎来到「mark」的世界！这不是一个简单的问答工具，而是你的战略思维伙伴。在这充满对立的时代，mark 帮你拒绝非此即彼，找到那条既明智又可行的第三条路。

## 🎯 什么是 mark？

```
    ┌─────────────────────────────────────────┐
    │  mark  •  渐进主义政治顾问              │
    │                                         │
    │   🇪🇺 欧式战略思维                      │
    │   🔄 拒绝二元对立                       │
    │   ⚖️ 寻找平衡之道                       │
    │   📈 渐进式变革                         │
    └─────────────────────────────────────────┘
```

mark 是一个基于欧洲精英思维模型的 AI 分析工具。它不是告诉你"选A还是选B"，而是帮你设计"既A又B"的综合方案。当你需要在环保与经济、改革与稳定、保护与开放之间找到平衡点时，mark 就派上用场了。

## ✨ 核心特性

### 🧭 四大思维引擎

```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│  🧠 平衡    │  🔄 渐进    │  🛡️ 自主    │  📊 数据    │
│             │             │             │             │
│  拒绝二元   │  稳定改革   │  合作独立   │  事实支撑   │

│  综合方案   │  凝聚共识   │  战略判断   │  论证有力   │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

**🧭 平衡思维**  
不问"要不要"，问"怎么同时做到"。环保与经济不是敌人，是可以共舞的伙伴。

**🔄 渐进改革**  
不搞大爆炸，也不原地踏步。小步快跑，稳步前进，在稳定中实现变革。

**🛡️ 战略自主**  
合作是手段，不是目的。保持独立判断，掌握关键领域的主动权。

**📊 数据驱动**  
不玩虚的，用事实说话。每个观点都有支撑，每个建议都有依据。

## ✨ 核心特性

### 🧭 四大思维引擎

```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│  🧠 平衡    │  🔄 渐进    │  🛡️ 自主    │  📊 数据    │
│             │             │             │             │
│  拒绝二元   │  稳定改革   │  合作独立   │  事实支撑   │
│  寻找中间   │  分阶段推   │  关键主导   │  逻辑严谨   │
│  综合方案   │  凝聚共识   │  战略判断   │  论证有力   │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

**🧭 平衡思维**  
不问"要不要"，问"怎么同时做到"。环保与经济不是敌人，是可以共舞的伙伴。

**🔄 渐进改革**  
不搞大爆炸，也不原地踏步。小步快跑，稳步前进，在稳定中实现变革。

**🛡️ 战略自主**  
合作是手段，不是目的。保持独立判断，掌握关键领域的主动权。

**📊 数据驱动**  
不玩虚的，用事实说话。每个观点都有支撑，每个建议都有依据。
